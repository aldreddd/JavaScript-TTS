# JavaScript TTS

A simple Text-to-Speech (TTS) project built with **JavaScript** and **Microsoft Edge TTS** using the `msedge-tts` package.

The project converts text into spoken audio.

## Features

- Convert text into speech using Microsoft Edge TTS.
- Generate audio output in MP3 format.
- Built with JavaScript and Node.js.

## Requirements

Before running the project, make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/aldreddd/JavaScript-TTS.git
   ```

2. Navigate to the project folder:

   ```bash
   cd JavaScript-TTS
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

## Usage

Run the JavaScript file:

```bash
node script.js
```
